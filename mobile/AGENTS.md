This app uses React Navigation (not Expo Router) and shares the web CRM's logic from `../src/lib`. The rules are in `mobile/CLAUDE.md`; the data rules are in the repo root `CLAUDE.md`.

Expo changes between SDK releases: check `package.json` for the SDK version and the matching docs (https://docs.expo.dev/versions/v58.0.0/) before using an Expo API, and add packages with `npx expo install <package>`.
