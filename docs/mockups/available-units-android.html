What changes (phone only)

  1. ASubtitle hidden. Manage becomes an icon button beside the project picker: one row, not two.
  2. BStatus chips stay on one row, scroll sideways, and fade at the edge so the hidden ones are discoverable.
  3. CThe floor rail becomes a dropdown, left of a compact search box. Each floor in it shows its free units.
  4. DSeats use the full width, 6 a row. Only free seats have an outline (soft green box). Taken seats have no outline: a light status-coloured number and a dot in the status colour, the same dot as the chips.
  5. EGrid gets bottom padding for the dock and the iPhone home bar, so the last row is never hidden.
  6. FSearch text is 16px, so iOS Safari does not zoom on tap.
  7. GManage on Projects is an outline button; the solid green stays on the active tab only.
  8. H"Semi Basement" shows as SB, not Sem.

Units, sizes, statuses and counts on the 1st floor and in the project list come from the current app screenshots. Free counts on the other floors are sample values. PC layout is unchanged.
