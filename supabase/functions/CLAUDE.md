# Edge Functions

Edge Functions in `supabase/functions/` handle the WhatsApp relay (`wa-send`, `wa-webhook`) and the two WhatsApp bots (`wa-bot-eyad`, `wa-bot-dubai` — ported from the n8n "Wecon WA Bot" / "Wecon WA Bot Dubai" workflows). A Wasender session only accepts one webhook URL, so each bot IS that session's webhook target and forwards the untouched payload to `wa-webhook` itself (`forwardToMirror`, fire-and-forget, `?account=dubai|eyad`) so the CRM-chat mirror still runs. Each bot also runs a FAQ agent (`runFaqAgent`, `supabase/functions/_shared/ai.ts`) on real inbound text once a human hasn't taken over (`/t`): OpenRouter answers from the `wa_projects` catalog only, short replies matching the existing template tone, and can follow up with a photo/floor-plan/brochure. Its replies are mirrored into `wa_conversations`/`wa_messages` via `sendWaMessageMirrored` so they show in Conversations like a human agent's.

Auto-forward (a contact gets a lead and an agent without a human typing the `/f…` tag) runs through the same `wa_create_lead` RPC as the manual tags and lives in `_shared/forward.ts` (rules in `forward-core.ts`): Eyad contacts after 5 minutes (`forwardDueContacts`, a `wa-followup` pass, `/fctg`, switch = Eyad's "Auto forward"), Facebook forms set to "Forward" (`fb-leads.ts`), and Dubai at once in `wa-bot-dubai` (no customer message). The customer is told who their expert is only for a lead the call really created.
